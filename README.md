# Jacob Chin’s Blog

Personal research blog by Jacob Chin, published with GitHub Pages.

The canonical site is `https://jacobchin.github.io`. New articles should be published from this repository—not from the separate OpenAI Sites project.

## Publishing a new article

Add a Markdown file to `_posts` using the name `YYYY-MM-DD-short-title.md`. Include the same front matter fields as the first article. GitHub Pages will rebuild the homepage and article automatically after the file is pushed to `main`.
